# DoorMart 

A local area shop delivery web application that allows customers to order from nearby shops online.

## Problem it solves
In many local villages, customers find it difficult to purchase items from nearby shops without physically visiting them. DoorMart provides a simple online platform where local shop owners can list their products and customers can place orders with cash on delivery — making shopping easier for everyone in the community.

## Features
- Customer registration and login
- Shop owner registration and login
- Owner dashboard to manage products
- Product availability tracking
- Customer can browse shops and products
- Place orders with cash on delivery

## Technologies Used
- HTML + CSS + JavaScript (Frontend)
- Java Servlet (Backend)
- JDBC (Database connection)
- MySQL (Database)
- GlassFish Server
- Apache Maven

## How to Run
1. Install NetBeans, JDK, GlassFish and MySQL
2. Create database using SQL scripts in `/sql` folder
3. Update database password in `DBConnection.java`
4. Run project in NetBeans with F6
